## 📊 Featured Projects

### 01 · [Help Desk Ticket Performance Analysis](https://github.com/mohammed-Alnaffaee/help-desk-ticket-performance-analysis/tree/portfolio-structure-review)

**Python · PostgreSQL · SQL · Statistics · Power BI**

Analyzed **19,714 historical help-desk tickets** and reconstructed their status timelines to assess a project-defined 72-hour operational target. Developed SQL checks, compared ticket types and projects, and built executive and workflow dashboards.

**Key finding:** **8,662** confirmed breaches among **19,605** evaluable tickets — a **44.18% conditional breach rate** under the project's documented measurement rules. *This is not an official contractual SLA.*

### 02 · [Student Dropout Prediction & Academic Success Support System](https://github.com/mohammed-Alnaffaee/student-dropout-prediction)

**Python · pandas · scikit-learn · Random Forest · Flask**

Developed an educational machine-learning prototype using **4,424 student records** to classify academic outcomes as **Dropout**, **Enrolled**, or **Graduate**. Built a bilingual **Arabic/English** Flask interface, with model evaluation and feature-importance reporting.

**Evaluation:** **73.22% test accuracy** on a held-out test set. Class-specific performance varies; the prototype is **not validated for real student-level decisions**.
